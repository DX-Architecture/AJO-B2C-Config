LocSync and Adobe Express Integration  
What It Is 
Build a custom Adobe Express Add-on — a side-panel UI that lives directly inside the Adobe 
Express editor. Users select subtitle text on their canvas, click "Translate with LocSync," and the 
translated text is written back to the design without leaving Adobe Express. 
How It Works 
Adobe Express Add-ons run in two isolated environments that talk to each other: 
┌──────────────────────────────────────────────────────────┐ 
│                  Adobe Express Editor                     │ 
│                                                           │ 
│  ┌──────────────────────┐   ┌───────────────────────┐    │ 
│  │     UI iframe         │   │   Document Sandbox    │    │ 
│  │  (LocSync panel HTML) │   │  (document read/write)│    │ 
│  │                       │   │                       │    │ 
│  │  ✅ fetch() to APIs   │   │  ✅ read text nodes   │    │ 
│  │  ✅ X-Api-Token auth  │   │  ✅ write translated  │    │ 
│  │  ❌ no doc access     │   │  ❌ no network calls  │    │ 
│  └──────────┬────────────┘   └───────────┬───────────┘    │ 
│             │       Comlink (bidirectional)│               │ 
│             └─────────────────────────────┘               │ 
└──────────────────────────────────────────────────────────┘ 
Step-by-step flow: 
1.​ User opens the LocSync panel in Adobe Express 
2.​ User selects the subtitle text block(s) on the canvas 
3.​ User picks source and target language in the panel, then clicks Translate 
4.​ The UI iframe calls POST /translate_chunks_start on the LocSync MT API with the 
X-Api-Token header 
5.​ The translated text is received in the UI iframe 
6.​ The result is passed via Comlink to the Document Sandbox 
7.​ The Sandbox uses fullContent.text (via @express-document-sdk) to write the 
translated text back to the TextNode 

--- PAGE 2 ---
8.​ The subtitle text on the canvas is updated in-place, preserving all styling 
What Adobe Added in Spring 2026 That Makes This Work 
The Spring 2026 Add-on SDK update introduced: 
●​
allDescendants and allTextContent accessors — read the full text content of every 
node on a page, including nested elements 
●​
TextContentModel interface — structured access to text data from any node 
●​
fullContent.text setter — direct text replacement while preserving character and 
paragraph styles 
These APIs allow the add-on to reason about the document at a semantic level (e.g., "this text is 
grouped with a video frame, so it is probably a subtitle"), which is exactly what LocSync needs.

Plan B: LocSync SRT Subtitle File 
Workflow 
What It Is 
Extend LocSync's existing Streamlit application with a dedicated "Video Subtitle Translation" feature. 
Users upload a video file or an existing SRT file, LocSync extracts the text content, sends it through 
the translation API, reassembles the result back into a valid SRT file with all original timestamps 
preserved, and the user downloads the translated SRT. 
How It Works 
User uploads the SRT file to LocSync

Two Sub-variants 
Plan B1 — SRT file upload only (no Adobe API dependency): 
●​
User must already have an SRT file (from Adobe Express Caption Video export, or any other 
source) 
●​
LocSync parses the SRT, translates the text, outputs a new SRT 
●​
Zero dependency on Adobe APIs 
●​
Implementable entirely within LocSync's existing Python/Streamlit stack 
Plan B2 — Video upload with Adobe Transcribe API: 
●​
User uploads a video directly; LocSync calls POST 
https://audio-video-api.adobe.io/v1/transcribe to get a timestamped SRT

Recommendation 
Run Plan A and Plan B1 in parallel: 
●​
Plan A delivers the "translate inside Adobe Express" experience that is the core of this 
initiative. Start with a proof of concept targeting simple TextNode translation. 
●​
Plan B1 (SRT file workflow) is low-risk and fast to build. It closes the gap for users who need 
timestamp-precise subtitle files and already work in Premiere Pro. 
Together they cover both the design-first user (social media, marketing) and the video-production 
user (episodic, localization-focused) without competing with each other.
